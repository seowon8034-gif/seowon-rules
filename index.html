규정 간 위임 관계

「규정명」 인용과 "~에 따라", "~으로 정한다", "준용한다" 문언을 분석해 상위·하위 규정을 찾습니다.

규정을 상위 법령과 대조

규정명을 입력하면 그 규정이 인용하거나 관련된 상위 법령을 찾습니다. 대조할 법령을 고르고 검증을 누르세요.

상위법 전체 자동 대조 (규정집 전체)

위에서 규정을 고르면 그 규정을 관련 상위 법령 전체와, 고르지 않으면 모든 규정을 자동으로 대조합니다. 의무·허용·기산점·요건(호) 같은 내용 차이와 "30주 이상", "3개월 이내" 같은 숫자 기준을 봅니다. 규정집 전체를 처음 대조할 때는 법령 조문 파일(약 8MB)을 내려받습니다.

규정 간 동일·유사 조항 찾기

서로 다른 규정에 같은(또는 거의 같은) 내용이 있는지 조·항 단위로 찾고, 기간·학점·인원 등 숫자가 다른 곳을 표시합니다.

규정 데이터 가져오기

서원대 규정집의 HWP 파일은 수집 프로그램(PC)이 직접 읽습니다. 앱에서 HWP 파일을 가져올 때는 한글에서 다른 이름으로 저장 → HWPX로 바꾼 뒤 가져오세요. 같은 이름의 규정은 새 내용으로 교체됩니다.

내보내기·초기화

데이터 업데이트 안내

규정이 개정되면 학교 PC에서 규정업데이트.bat(업데이트 프로그램)을 열고 업데이트 시작을 누르면 규정 수집, 국가법령정보센터 확인, 업로드가 한 번에 끝나고, 이 앱은 다음에 열 때 새 데이터로 바뀝니다.

서원대 규정집 자동 수집 안내

서원대학교 홈페이지 규정집(www.seowon.ac.kr)은 규정을 HWP 파일로 제공하고 다른 사이트에서 직접 불러올 수 없어(보안 정책), 수집 프로그램이 규정마다 최신 HWP를 받아 본문을 뽑아 data/rules.json으로 올려두면 이 앱이 그 파일을 읽습니다.
  1. PC에서 pip install olefile 후 python tools/seowon_rules_crawler.py 실행 → data/rules.json 생성
  2. 생성된 파일을 저장소에 올리면(커밋) 모든 사용자가 최신 규정 데이터 받기로 갱신
  3. 또는 생성된 JSON을 이 화면의 파일에서 가져오기로 직접 불러오기

국가 법령 인용 확인 안내

규정이 인용한 법률·시행령·시행규칙·고시가 현행인지, 인용한 조가 있는지는 국가법령정보센터(law.go.kr) Open API로 확인합니다.
  1. open.law.go.kr에서 OPEN API 신청: 인증키(OC)는 직접 정하고, PC의 공인 IP 등록, 현행법령·현행 행정규칙의 목록·본문 JSON 선택
  2. PC에서 python tools/law_check.py --oc 인증키 --text-dir data/lawtext 실행 → data/laws.json 생성
  3. 파일을 저장소의 data/에 올리거나, 이 화면의 파일에서 가져오기로 불러오기
확인 결과는 검증 탭의 상위법 비교에 쓰이고, 규정 본문에서 초록색 법령 인용을 누르면 현행 조문을 볼 수 있습니다.
